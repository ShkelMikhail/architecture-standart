### <a name="_3bfxc9a45514"></a>**Функциональные требования**

| № | Действующие лица или системы        | Use Case                        | Описание |
|:-:|-------------------------------------|----------------------------------|----------|
| 1 | Менеджер бэк-офиса                  | Обновление ставок                | Загружает и обновляет актуальные ставки по депозитам в XLS или через АБС |
| 2 | Система ставок (АБС/модуль XLS)     | Хранение ставок                  | Централизованное хранение и проверка актуальности ставок |
| 3 | Система кол-центра                  | Получение ставок                 | Получает актуальные ставки для отображения оператору |
| 4 | Оператор кол-центра                 | Консультирование клиентов        | Использует актуальные ставки для консультаций по телефону |
| 5 | Система ставок                      | Экспорт файла ставок             | Выгружает файл ставок для передачи партнёрскому кол-центру |
| 6 | Партнёрский кол-центр               | Получение файла ставок           | Получает файл ставок, использует для консультаций клиентов |

---

### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**

| № | Требование |
|:-:|:-----------|
| 1 | Обновление ставок для кол-центра должно происходить не реже 1 раза в час |
| 2 | Формат выгружаемого файла ставок — XLSX или CSV |
| 3 | Передача файла в партнёрский кол-центр — вручную или по защищённому каналу (например, email) |
| 4 | История изменений ставок хранится не менее 6 месяцев |
| 5 | Решение не должно требовать значительных изменений в системах кол-центра и партнёра |
| 6 | Доступ к ставкам для операторов кол-центра — через внутренний интерфейс или единый файл |

---

### <a name="_qmphm5d6rvi3"></a>**Решение**

- Для хранения ставок используется текущий модуль ставок (XLS или АБС).
- Менеджер бэк-офиса обновляет ставки централизованно.
- Для внутреннего кол-центра реализуется доступ к этим ставкам через внутренний интерфейс или файл.
- Для партнёрского кол-центра организуется регулярная (по расписанию) выгрузка актуального файла ставок (XLSX или CSV), который передаётся по защищённому каналу (например, email).
- Операторы обоих кол-центров используют эти ставки для консультаций клиентов.

**Аргументация:**  
Решение минимально затрагивает текущие системы, не требует сложной интеграции с внешним партнёром, обеспечивает оперативное обновление ставок и прозрачную передачу информации.

---

### <a name="_bjrr7veeh80c"></a>**Альтернативы**

- **API-интеграция для партнёрского кол-центра:**  
  Не реализуема из-за ограничений внешней системы партнёра.
- **Ручная рассылка ставок операторам:**  
  Высокий риск ошибок, неудобство, не масштабируется.
- **Автоматизация с помощью корпоративного портала:**  
  Требует наличия у партнёра доступа к порталу, не всегда возможно.

---

**Недостатки, ограничения, риски**

- Возможна задержка или ошибка при ручной передаче файла партнёру.
- Возможна несвоевременная загрузка файла ставок в партнёрском кол-центре.
- Временной лаг между обновлением ставок и получением файла партнёром.
- Нет автоматизированного контроля версий ставок у партнёра.
